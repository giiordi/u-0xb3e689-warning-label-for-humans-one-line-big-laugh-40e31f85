The safety warning label that should come printed on every human being —
one line, funny first, plausible second.

The line:

> WARNING: Contains one (1) human. Runs on caffeine, spite, and three hours of sleep. Do not shake. Saying 'calm down' voids the warranty.

It reads like a real printed label — contents, handling instructions, a
warranty clause — and the joke is recognition: the human runs on caffeine,
spite and too little sleep, and the one thing guaranteed to make it worse
is telling it to calm down. The laugh lands in the last few words.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

`main.ts` (Node 22, stdlib only) writes the line to `entry.txt` in the
output directory, with no trailing newline so the file is exactly one
line. It validates the gate itself: 1–160 characters, a single line,
not only white space, no leading/trailing whitespace, no control
characters.
